## What's included

- **Visual system:** light mode, navy/blue foundation, restrained semantic colors, Inter typography, rounded surfaces, spacing, borders and shadows.
- **Screen specifications:** login, password recovery, institution dashboard, official scrutiny console, application review, deficiencies, resubmissions, compliance, EVC, committee proceedings, administrator console and audit trail.
- **Component system:** shared navigation, tables, forms, status badges, document viewers, timelines, dialogs and empty/error states.
- **Expanded library choices:** shadcn/ui as a foundation—not a restriction—plus Lucide React, Tabler Icons, Motion for React, GSAP, ReactBits, Lenis, TanStack Table, and alternatives for charts and forms.
- **Technical alignment:** React, TypeScript, Vite, Tailwind CSS, React Router, Express APIs, Neon PostgreSQL, Prisma, authentication, RBAC and private document storage.
- **Implementation instructions:** repository inspection, API integration, responsive behavior, accessibility, testing and acceptance criteria.

## Important constraints preserved

1. The Stitch screenshots and HTML are **visual references**, not the source of truth for application content or backend behavior.
2. Existing API contracts, database models, permissions and approved regulatory workflows determine what each screen displays and allows.
3. AI/OCR functionality remains out of scope until you explicitly authorize its implementation.
4. Lenis, GSAP and other animation libraries are optional tools, not dependencies to install indiscriminately.
